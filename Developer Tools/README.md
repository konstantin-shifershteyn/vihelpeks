# Developer Tools (`/Developer Tools/`)

This folder contains VIs, tools, and assets used for the development of VI Helpeks.

---

## Files & Sub-Folders

* `VI Helpeks VIs.vi` - Block Diagram of this VI contains most significant toolkit VIs (top-level, dialogs, API, example, utility, etc. VIs). Opening this VI loads all VI Helpeks VIs into memory simultaneously.

* `/Help Project/` folder contains configuration and source files to generate VI Helpeks end-user documentation.

* `/Icon/` folder contains icon and picture files used throughout the toolkit's user interface.

* `/Utility VIs/` folder contains miscellaneous helper VIs used during development.
