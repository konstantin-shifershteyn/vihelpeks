Compiled HTML Help

VI Helpeks does not create compiled help files (CHM) directly; instead, it generates HTML Help Project (HHP file with relevant contents and index files) and calls HTML Help Compiler (comes with Microsoft HTML Help Workshop) for compiling a help file from the project.

Furthermore, you can open the generated HTML Help Project in the HTML Help Workshop or other help authoring application (e.g. FAR) with the purpose to edit and compile the project.

NOTE: In order to create compiled HTML help (CHM) in VI Helpeks, you must have HTML Help Workshop installed on your computer. You can download it for free at Microsoft website:
http://msdn.microsoft.com/en-us/library/ms669985.aspx
Microsoft HTML Help home page:
http://msdn.microsoft.com/en-us/library/ms670169.aspx

 

TIP: Use Build >> Compiled HTML Help menu to open a utility that help you to create compiled help file from HTML files generated for the current VI Helpeks project.
