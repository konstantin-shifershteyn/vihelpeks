This document provides an overview of the toolkit and describes the Basic Concepts of help projects. For additional assistance, use the native LabVIEW Context Help (Ctrl+H). It provides detailed information on every control and indicator inside the main VI Helpeks window (the help project manager) and its dialogs, as well as relevant background information.

Tools and Utilities

VI Helpeks tools and utilities can be found in the LabVIEW Tools >> VI Helpeks menu:

  • VI Helpeks project manager is the main tool to edit and build help projects. Use it to create HTML/CHM help for your VIs.
  • VI Documentation utility provides an easy way to define the documentation properties of a VI, as well as its controls and indicators. When launched from the Tools menu within a VI, the utility automatically operates on that VI.
  • Mass compile VI Helpeks performs mass compiling of the VI Helpeks VIs.

API VIs

API VIs are intended to build help projects programmatically and assist developers in creating help system for their VIs. API VIs can be found in the Addons >> VI Helpeks API function palette.

Examples

  • Help Project examples
    VI Helpeks includes several example projects that demonstrate its capabilities and specific usage details. You can review these examples by selecting an item in the Help >> Open Example Project menu in the main VI Helpeks window. Feel free to build the example projects to see the outputs for yourself.
  • API VIs examples
    The example VI demonstrating the use of VIHelpeks API can be opened using the Tools >> VI Helpeks >> Help and Support menu. Alternatively, you can launch the NI Example Finder and search for "VI Helpeks", or find it within the <labview>\Examples\VI Helpeks folder.
