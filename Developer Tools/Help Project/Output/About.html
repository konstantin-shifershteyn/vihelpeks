This document provides an overview of the toolkit and describes the Basic Concepts of help projects. For additional assistance, use the LabVIEW Context Help (Ctrl+H). It provides detailed information on every control and indicator in the main VI Helpeks window (help project manager) and dialogs, as well as relevant background information.

Tools and Utilities

VI Helpeks tools and utilities can be found in the LabVIEW Tools >> VI Helpeks menu:

  • VI Helpeks project manager is the main tool to edit and build help projects. Use it to create HTML/CHM help for your VIs.
  • VI Documentation utility provides an easy way to define the documentation properties of a VI, as well as its controls and indicators. When launched from the Tools menu within a VI, the utility automaticaly operates on that VI.
  • VI Helpeks Help opens this document.
  • VI Helpeks License opens the VI Helpeks Software License Agreement.
  • VI Helpeks Website opens the VI Helpeks WEB site.
  • Mass compile VI Helpeks performs mass compiling of the VI Helpeks VIs.

API VIs

API VIs are intended to build help projects programmatically and assist developers in creating help system for their VIs. API VIs can be found in the Addons >> VI Helpeks API function palette.

Examples

  • Help Project examples
    VI Helpeks includes several example projects that demonstrate its capabilities and specific usage details. You can review these examples by selecting an item in the Help >> Open Example Project menu in the main VI Helpeks window. Feel free to build the example projects to see the outputs for yourself.
  • API VIs examples
    Examples of API VIs usage can be found in the <labview>\Examples\VI Helpeks folder. Alternatively, you can launch the NI Example Finder and search for "VI Helpeks".
