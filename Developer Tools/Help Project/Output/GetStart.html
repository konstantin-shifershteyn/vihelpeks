Create your first help


This topic briefly describes the steps to build your first help project.


1. Create a project

Use the File >> New Project menu to create a new empty project. Select a project type in the dialog that appears and click OK. Note: you can change the project type later.


2. Add files to the project

Use the Project >> Add to project menu to add the files (e.g. VIs) for which you want to generate help files.


3. Define the destination folder (optional)

You might want to change the target folder where help files will be generated. To do this, select either the Help Project or Project Files item in the Project Tree, select the Target Paths category, and specify the desired path in the Build Root Folder control.


4. Save the project (optional)

Use the File >> Save Project menu to save the project file.


5. Build help files

Use the Project >> Build Help for All menu to build help for all source files in the project.


6. Review the built help

Select a source file in the project tree and use the Project >> Open Output Help File menu to open the generated help file.


7. Create a compiled help file (optional)

Use the Build >> Compiled HTML Help menu to open a utility that assists you in creating a Compiled HTML Help file (CHM) from the generated HTML files.
