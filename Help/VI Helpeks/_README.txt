VI HELPEKS

Thank you for installing VI Helpeks and welcome to our community!

This product features a rich history of active development and successful use
worldwide. The author sincerely hopes you find it convenient and effective
for developing your VI documentation.


## LINKS & REPOSITORY (Source Code, Updates & Changelog)
------------------------------------------------------------------------------
Starting with Version 3.1, the entire VI Helpeks project is open-source under 
the terms of the MIT License. You can find the source code for the entire
project, including VIs, tools and all assets, on the official GitHub page:

https://github.com/konstantin-shifershteyn/vihelpeks


## MAINTENANCE, BUG REPORTING & SUPPORT
------------------------------------------------------------------------------
VI Helpeks is a mature product provided strictly "AS IS", WITHOUT WARRANTY OF 
ANY KIND. The individual author no longer guarantees technical support,
ongoing updates, or direct email troubleshooting.

If you encounter an edge-case bug, wish to propose a feature optimization, 
or want to contribute a code fix, you are enthusiastically welcome to submit 
a formal Pull Request directly on our GitHub project page.


## SUPPORT THE PROJECT
------------------------------------------------------------------------------
VI Helpeks Toolkit is distributed 100% free of charge to maximize adoption 
and accessibility across the global LabVIEW community. However, maintaining

If VI Helpeks saves your team valuable hours or is actively used in your
projects or documentation workflows, please consider supporting the author's

Support and sponsorship details can be found on the official project page:
